# Installation

## Using pip

```bash
pip install pikahttp
```

## From source

1. Clone the repository:
   ```bash
   git clone https://github.com/GrandmaEJ/pikahttp.git
   cd pikahttp
   ```

2. Install with maturin:
   ```bash
   pip install maturin
   maturin develop
   ```

## Requirements

- Python 3.7 or later
- Rust stable toolchain (for building from source)
